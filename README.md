# Установка Claude Desktop для Windows

Небольшой установщик для коллеги: получает актуальную сборку Claude Desktop напрямую из официального сервиса Anthropic и проверяет цифровую подпись до запуска. Python и WinGet не нужны. Сам установочный файл в репозиторий не включён.

## Что нужно

- Windows 10 или Windows 11, x64 или ARM64.
- Интернет.
- Claude Setup может запросить подтверждение Windows. Если администраторские права недоступны, установщик предлагает продолжить без Cowork; базовый Claude Desktop можно установить отдельно.
- Claude Cowork требует прав администратора и включённой платформы виртуальной машины. Для Developer Mode и дальнейшей настройки откройте Claude после установки.

## Установка

1. Скачайте ZIP проекта через **Code → Download ZIP** или клонируйте репозиторий.
2. Распакуйте архив.
3. Дважды нажмите `Установить-Claude.cmd`.
4. Дождитесь загрузки официального Claude Setup и следуйте его шагам. Если запрос прав администратора недоступен, выберите установку без Cowork.
5. Откройте Claude из меню «Пуск», войдите в свой аккаунт и настройте Developer Mode.

Также можно запустить PowerShell от имени пользователя и выполнить:

```powershell
.\Install-Claude.ps1
```

Скрипт не использует WinGet и проверяет Authenticode-подпись Anthropic перед запуском установщика. Он не читает и не переносит пароли, токены, настройки, чаты или данные аккаунта отправителя.

## Удаление

В Windows откройте **Параметры → Приложения → Установленные приложения → Claude → Удалить**.
