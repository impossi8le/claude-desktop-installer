# Установка Claude Desktop для Windows

Небольшой установщик для коллеги: скачивает и устанавливает Claude Desktop через WinGet из каталога Microsoft. Сам установочный файл в репозиторий не включён: WinGet получает актуальный пакет Anthropic и сверяет его контрольную сумму по манифесту.

## Что нужно

- Windows 10 или Windows 11, x64 или ARM64.
- Интернет.
- WinGet (Windows Package Manager, обычно поставляется с App Installer).
- Для Claude Cowork на Windows могут понадобиться права администратора и включённая платформа виртуальной машины. Обычная установка приложения и вход в Claude — отдельные шаги.

## Установка

1. Скачайте ZIP проекта через **Code → Download ZIP** или клонируйте репозиторий.
2. Распакуйте архив.
3. Дважды нажмите `Установить-Claude.cmd`.
4. Если Windows покажет запрос контроля учётных записей, подтвердите его.
5. После установки откройте Claude из меню «Пуск» и войдите в свой аккаунт.

Также можно запустить PowerShell от имени пользователя и выполнить:

```powershell
.\Install-Claude.ps1
```

Скрипт устанавливает пакет `Anthropic.Claude` из источника WinGet с тихим режимом. Он не читает и не переносит пароли, токены, настройки, чаты или данные аккаунта отправителя.

## Удаление

В Windows откройте **Параметры → Приложения → Установленные приложения → Claude → Удалить**.
